# 🚀 Deploy no Railway - Passo a Passo

## 1. Criar conta no Railway
- Acesse: https://railway.app
- Faça login com GitHub

## 2. Conectar seu repositório
- Clique em "New Project"
- Selecione "Deploy from GitHub repo"
- Escolha seu repositório

## 3. Configurar deploy
O Railway detectará automaticamente que é um projeto Node.js

## 4. Variáveis de ambiente (se necessário)
- PORT já está configurado no código

## 5. Deploy automático
- O Railway fará deploy automaticamente
- Receberá uma URL como: https://seu-projeto.railway.app

## 6. Atualizar GitHub Pages
- No GitHub Pages, manter apenas o jogo offline
- Adicionar link para o servidor Railway
